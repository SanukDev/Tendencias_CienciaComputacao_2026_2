Projeto: TaskFlow AI
Sistema de gerenciamento de tarefas com Inteligência Artificial utilizando Bubble.


1. Descrição do projeto
O TaskFlow AI será uma aplicação web para cadastro e gerenciamento de tarefas pessoais ou acadêmicas.

O usuário poderá cadastrar tarefas, definir prazos, acompanhar o andamento e utilizar a Inteligência Artificial para gerar sugestões de organização e planejamento.

O projeto será desenvolvido utilizando a plataforma Bubble, que permite criar aplicações por meio de ferramentas visuais, reduzindo a necessidade de programação tradicional.
2. Objetivo geral
Desenvolver um protótipo funcional de gerenciamento de tarefas utilizando a plataforma Bubble, demonstrando como ferramentas Low Code, No Code e recursos de Inteligência Artificial podem simplificar e acelerar o desenvolvimento de software.
3. Funcionalidades
O sistema contará com funcionalidades simples:
- Cadastro de tarefas.
- Definição de título, descrição e prazo.
- Organização por status: pendente, em andamento e concluída.
- Visualização das tarefas cadastradas.
- Integração com IA para sugerir formas de organizar as tarefas.
Exemplo de funcionamento
O usuário cadastra a seguinte tarefa:

"Estudar para a prova de Linguagens Formais."

A IA poderá sugerir:
- Dividir o conteúdo em etapas de estudo.
- Definir uma ordem de prioridade.
- Recomendar um planejamento de estudo.
4. Plataforma escolhida
A plataforma utilizada será o Bubble.

A escolha se justifica por permitir:
- Criar interfaces visualmente.
- Configurar um banco de dados.
- Definir regras e automações.
- Integrar serviços externos de Inteligência Artificial.
5. Fundamentação tecnológica
O projeto utilizará três abordagens:
Tecnologia	Aplicação no projeto
Low Code	Construção da aplicação por meio de recursos visuais e configurações.
No Code	Criação das telas, formulários e fluxos sem programação tradicional.
Vibecode	Utilização de prompts de IA para auxiliar na criação de funcionalidades e lógica.

6. Etapas do desenvolvimento
1. Definir o problema: dificuldade em organizar tarefas e prazos.
2. Desenvolver a interface e o banco de dados no Bubble.
3. Criar os fluxos de cadastro e atualização das tarefas.
4. Integrar a Inteligência Artificial.
5. Testar e documentar o protótipo.

7. Organização da equipe
Para três estudantes:
- Estudante 1: Interface e protótipo.
- Estudante 2: Banco de dados e automações.
- Estudante 3: Integração com IA, testes e documentação.
8. Produtos esperados
Ao final do projeto, serão entregues:
- Protótipo funcional no Bubble.
- Link de acesso à aplicação.
- Repositório GitHub com documentação.
- Screenshots das funcionalidades.
- Apresentação final em slides.
9. Reflexão crítica
Vantagens
1. Desenvolvimento mais rápido.
2. Facilidade na criação de interfaces.
3. Integração simplificada com serviços externos.
Limitações
1. Dependência da plataforma Bubble.
2. Limitações de personalização.
3. Possíveis custos para funcionalidades avançadas.
